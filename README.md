One sentence (194 characters) explaining the modern internet to a time
traveler from 1800, built only from things a person of that year already
knows: a road, a post office, a library, a market, a letter, ink.

> Picture one road joining every library, post office, and market on earth,
> where a letter reaches the far side of the world before its ink dries,
> and all mankind walks it together, day and night.

## Run

```sh
python3 main.py
# writes /output/entry.txt
```
